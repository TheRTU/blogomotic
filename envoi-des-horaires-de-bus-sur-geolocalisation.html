Envoi des horaires de bus sur géolocalisation

Afficher les prochains bus lors de l’arrivée dans une zone

Cette automatisation se déclenche lorsqu’une personne entre dans une zone définie, par exemple une gare ou un pôle d’échanges.

Home Assistant récupère alors les horaires des deux prochains départs d’une ligne de bus et calcule le nombre de minutes restantes à partir de l’heure courante. Une notification est ensuite envoyée directement sur le téléphone concerné.

Cela permet d’avoir automatiquement les prochains départs sous les yeux au moment où l’information devient utile, sans avoir à ouvrir une application de transport.

Le YAML :

alias: Annonce bus à l'arrivée en gare
description: Notification des prochains bus lors de l'arrivée en gare

triggers:
  - trigger: zone
    entity_id: person.personne_1
    zone: zone.gare_principale
    event: enter

conditions: []

actions:
  - variables:
      premier_depart: >
        {{ as_timestamp(
             states('sensor.bus_prochain_depart'),
             default=none
           ) }}

      deuxieme_depart: >
        {{ as_timestamp(
             states('sensor.bus_2eme_depart'),
             default=none
           ) }}

  - action: notify.mobile_app_telephone_personne_1
    data:
      title: "🚌 Prochains départs"
      message: >-
        Ligne de bus ➜ Destination

        {% if premier_depart | float(none) is not none %}
          • dans {{ [0,
            ((premier_depart | float - now().timestamp()) / 60)
            | round(0) | int
          ] | max }} min
        {% else %}
          • premier départ indisponible
        {% endif %}

        {% if deuxieme_depart | float(none) is not none %}
          • dans {{ [0,
            ((deuxieme_depart | float - now().timestamp()) / 60)
            | round(0) | int
          ] | max }} min
        {% else %}
          • deuxième départ indisponible
        {% endif %}

mode: single
  • déclenchement par entrée dans une zone géographique ;
  • utilisation de données de transport en temps réel ;
  • calcul du nombre de minutes restantes avec un template Jinja ;
  • notification personnalisée envoyée au téléphone.
