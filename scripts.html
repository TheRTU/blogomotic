Scripts

Dans Home Assistant, un script permet d'enchaîner une ou plusieurs actions et de les regrouper sous une seule commande.

Contrairement à une automatisation, un script ne possède pas de déclencheur.

Une automatisation répond généralement à la question :

"Quand faut-il agir ?"

Un script répond plutôt à :

"Que faut-il faire ?"

Cette distinction permet de séparer plus proprement les différentes fonctions de Home Assistant.

À quoi sert un script ?

Un script peut, par exemple :

  • allumer ou éteindre plusieurs équipements ;

  • envoyer des notifications ;

  • lancer une annonce vocale ;

  • modifier le volume d'une enceinte ;

  • déclencher plusieurs actions les unes après les autres ;

  • ajouter des délais entre différentes étapes.

Une fois créé, il peut être lancé manuellement depuis Home Assistant ou être appelé depuis une automatisation, un dashboard ou même un autre script.

Cela permet surtout d'éviter de répéter plusieurs fois la même séquence d'actions.

Scripts et automatisations

Les deux sont très complémentaires.

Une automatisation peut détecter un événement, vérifier certaines conditions, puis appeler un script chargé d'exécuter les actions nécessaires.

Cette organisation devient particulièrement pratique lorsque plusieurs automatisations doivent déclencher la même série d'actions.

Les scripts ne sont donc pas indispensables pour débuter avec Home Assistant, mais ils deviennent rapidement utiles lorsque l'installation commence à prendre de l'ampleur.

Exemple d’un script permettant de piloter simultanément Alarmo et l’alarme intégrée de la Freebox : 

alias: Alarmes - Bascule globale
description: Active ou désactive Alarmo et l'alarme Freebox simultanément
mode: single
sequence:
  - choose:
      - conditions:
          - condition: template
            value_template: |
              {{
                is_state('alarm_control_panel.alarmo', 'disarmed')
                and
                is_state('alarm_control_panel.systeme_d_alarme', 'disarmed')
              }}
        sequence:
          - action: alarm_control_panel.alarm_arm_away
            target:
              entity_id:
                - alarm_control_panel.alarmo
                - alarm_control_panel.systeme_d_alarme
    default:
      - action: alarm_control_panel.alarm_disarm
        target:
          entity_id:
            - alarm_control_panel.alarmo
            - alarm_control_panel.systeme_d_alarme
