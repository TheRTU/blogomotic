Raspberry Pi 4

Raspberry Pi 4 : le cœur de mon installation domotique

Le Raspberry Pi 4 est actuellement le cerveau de mon installation Home Assistant. C'est lui qui centralise les équipements, exécute les automatisations et héberge les différentes intégrations.

Après avoir utilisé Home Assistant dans une machine virtuelle sur ma Freebox Delta, j'ai préféré passer à une solution dédiée, plus simple à administrer et indépendante de la box Internet.

Caractéristiques et configuration

Voici la configuration que j'utilise :

  • Modèle : Raspberry Pi 4 Model B
  • Mémoire vive : 4 Go de RAM
  • Processeur : Broadcom BCM2711, quatre cœurs ARM Cortex-A72 à 1,5 GHz
  • Stockage : carte microSD SanDisk MAX ENDURANCE de 128 Go
  • Système : Home Assistant OS (HAOS)
  • Connexion réseau : Ethernet
  • Alimentation secourue : onduleur Eaton 3S700F

Home Assistant OS est installé directement sur le Raspberry Pi, sans système Linux supplémentaire à administrer.

Pourquoi un Raspberry Pi ?

Mon installation fonctionnait auparavant dans une machine virtuelle hébergée sur la Freebox Delta.

Cette solution avait l'avantage de ne nécessiter aucun matériel supplémentaire, mais elle rendait Home Assistant dépendant de la box.

Le passage sur Raspberry Pi m'a permis de disposer d'un système autonome, exclusivement consacré à la domotique.

Autre avantage : sa consommation électrique reste très faible, un point intéressant pour un appareil destiné à fonctionner 24 heures sur 24.

Les performances au quotidien

Malgré sa taille modeste, le Raspberry Pi 4 assure correctement son rôle.

Il gère mes nombreux équipements, mes automatisations, mes tableaux de bord et plusieurs intégrations personnalisées.

Avec ses 4 Go de RAM, il répond actuellement à mes besoins, sans difficulté majeure.

Pour les opérations plus gourmandes, notamment la compilation de mes projets ESPHome, j'utilise mon PC Linux afin de ne pas solliciter inutilement le Raspberry Pi.

Le stockage : une carte microSD adaptée

J'utilise une carte SanDisk MAX ENDURANCE de 128 Go, conçue pour supporter des écritures fréquentes.

Ce choix est important : Home Assistant enregistre régulièrement des états, des événements et des historiques dans sa base de données.

Une carte microSD classique peut s'user prématurément dans ce type d'utilisation.

Même avec une carte haute endurance, le risque de défaillance n'est pas nul. Des sauvegardes régulières restent donc indispensables.

Sécurité et sauvegardes

Le Raspberry Pi est alimenté par un onduleur Eaton 3S700F, qui permet de limiter les conséquences des coupures électriques.

Home Assistant réalise également des sauvegardes automatiques, avec une copie externalisée sur OneDrive.

Pour l'accès à distance, j'utilise principalement WireGuard et Home Assistant Cloud (Nabu Casa).

Le port 8123 de Home Assistant n'est pas directement exposé sur Internet.

Mon avis

Après plusieurs mois d'utilisation, le Raspberry Pi 4 me donne entière satisfaction.

Ses points forts :

  • Faible consommation électrique.
  • Fonctionnement silencieux.
  • Installation simple de Home Assistant OS.
  • Performances suffisantes pour mon installation.
  • Communauté importante et documentation abondante.

Ses limites :

  • Puissance inférieure à celle d'un mini-PC récent.
  • Stockage microSD moins robuste qu'un SSD.
  • Ressources limitées pour les traitements intensifs.

Pour mon utilisation actuelle, je ne ressens pas le besoin de passer à une machine plus puissante pour l'instant.
