Alerte de température anormale du congélateur

Alerte de température anormale du congélateur

Cette automatisation surveille en permanence la température du congélateur. Si celle-ci reste au-dessus de -5 °C pendant 45 minutes, Home Assistant considère qu’il peut y avoir un problème et déclenche plusieurs alertes.

La température mesurée est d’abord enregistrée dans une variable, puis reprise dans les différents messages envoyés. Les occupants reçoivent une notification sur leur téléphone, une annonce vocale est diffusée sur plusieurs enceintes et une notification persistante est également créée dans Home Assistant.

Le délai de 45 minutes permet d’éviter les fausses alertes lors d’une ouverture prolongée de la porte ou pendant une variation temporaire de température.

Le YAML :

alias: Alerte température haute congélateur
description: Alerte si le congélateur reste au-dessus de -5 °C pendant 45 minutes

triggers:
  - trigger: numeric_state
    entity_id:
      - sensor.temperature_congelateur
    above: -5
    for: "00:45:00"

conditions: []

actions:
  - variables:
      temperature: |
        {{ states('sensor.temperature_congelateur') | float(0) | round(1) }}

  - action: notify.mobile_app_telephone_1
    data:
      title: Problème congélateur
      message: |
        Le congélateur est à {{ temperature }} °C depuis au moins 45 minutes.

  - action: notify.mobile_app_telephone_2
    data:
      title: Problème congélateur
      message: >
        Le congélateur est à {{ temperature }} °C depuis au moins 45 minutes.
        Vérification nécessaire.

  - action: notify.alexa_media_enceinte_cuisine
    data:
      message: >
        Attention. Le congélateur est à {{ temperature }} degrés depuis au moins
        quarante-cinq minutes.

  - action: notify.alexa_media_enceinte_salon
    data:
      message: >
        Attention. Le congélateur est à {{ temperature }} degrés depuis au moins
        quarante-cinq minutes.

  - action: notify.persistent_notification
    data:
      title: Problème congélateur
      message: >
        Le congélateur est à {{ temperature }} °C depuis au moins 45 minutes.
        Vérification nécessaire.

mode: single
  • surveillance d’un seuil de température avec numeric_state ;
  • maintien du seuil pendant 45 minutes avant déclenchement ;
  • utilisation d’une variable pour réutiliser la température mesurée ;
  • diffusion de l’alerte sur plusieurs canaux ;
  • notification persistante dans Home Assistant en complément des alertes mobiles et vocales.
