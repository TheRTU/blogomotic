Coupure climatisation sur fenêtre ouverte

Cette automatisation surveille les fenêtres du salon et de la salle à manger. Si l’une d’elles reste ouverte pendant plus de 5 minutes, Home Assistant coupe automatiquement la climatisation, sauf si elle fonctionne uniquement en mode ventilation.

Avant l’arrêt, le mode de fonctionnement en cours est mémorisé. L’automatisation attend ensuite que toutes les fenêtres soient refermées, puis restaure automatiquement le mode précédent de la climatisation.

L’objectif est simple : éviter de climatiser inutilement avec une fenêtre ouverte, sans perdre le réglage qui était actif avant la coupure.

Par l'éditeur visuel :

Le code en YAML :

alias: Clim salon - Coupure fenêtres ouvertes
description: >
  Coupe la clim si une fenêtre du salon ou de la salle à manger reste ouverte
  plus de 5 minutes, sauf en mode ventilation seule. Restaure le mode précédent
  lorsque toutes les fenêtres sont fermées.
triggers:
  - trigger: state
    entity_id: binary_sensor.salon_fenetre_1
    to: 'on'
    for:
      minutes: 5
  - trigger: state
    entity_id: binary_sensor.salon_fenetre_2
    to: 'on'
    for:
      minutes: 5
  - trigger: state
    entity_id: binary_sensor.capteur_fenetre_sam
    to: 'on'
    for:
      minutes: 5
conditions:
  - condition: template
    value_template: |
      {{ states('climate.clim_salon') not in ['off', 'fan_only',
                                              'unknown', 'unavailable'] }}
actions:
  - variables:
      mode_avant_coupure: '{{ states(''climate.clim_salon'') }}'
  - action: climate.turn_off
    target:
      entity_id: climate.clim_salon
  - wait_template: |
      {{
        is_state('binary_sensor.salon_fenetre_1', 'off')
        and
        is_state('binary_sensor.salon_fenetre_2', 'off')
        and
        is_state('binary_sensor.capteur_fenetre_sam', 'off')
      }}
  - action: climate.set_hvac_mode
    target:
      entity_id: climate.clim_salon
    data:
      hvac_mode: '{{ mode_avant_coupure }}'
mode: single
  • déclenchement après 5 minutes d’ouverture ;
  • surveillance de plusieurs fenêtres dans une seule automatisation ;
  • exclusion du mode fan_only ;
  • mémorisation du mode actif avant coupure ;
  • reprise automatique quand toutes les fenêtres sont fermées.
